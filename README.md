# Say it — веб-тренажёр английского

[Открыть Say it](https://safal207.github.io/english-zero-to-fluent-pages/)

Бесплатный тренажёр английского с первым устным ответом сразу после открытия. Выбери короткий режим на 2, 5 или 10 минут: в новой ситуации послушай собеседника, повтори ответ с опорой и скажи без текста. При повторении сначала вспомни ответ и оцени первую попытку, затем сравни с образцом. После самостоятельного ответа приложение предложит следующую ситуацию, если другие повторы ещё не наступили. В 10-минутном режиме у каждой из 42 тем есть отдельная ситуация для переноса ответа. В программе также 126 упражнений и 168 карточек. Интерфейс адаптирован для телефона.

Можно добавить до 20 своих фраз за раз из интересного видео или текста, использовать их в диалоге и вернуться к ним по памяти через два дня. Всего хранится до 2000 личных фраз. Сайт готовит текст задания для внешнего чата, но сам ничего туда не отправляет.

Этот репозиторий содержит только файлы веб-приложения, без истории основного приватного репозитория и без пользовательских сохранений. Для работы не нужны платные API или ключи.

## Публикация

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. После обновления файлов в этой ветке GitHub автоматически обновляет сайт. Это отдельная копия: изменения в основном приватном репозитории нужно сначала перенести сюда.

## Прогресс

Прогресс, незавершённый шаг урока и короткой практики, введённый в ней текст, личные фразы и назначенные повторы хранятся в браузере. При переходе с другого адреса скачай резервную копию в разделе «Мой прогресс» прежнего сайта и загрузи её здесь. Аудиозаписи нужно сохранять отдельно: они остаются только в памяти вкладки до ухода с экрана. Сервер не получает учебный прогресс и записи голоса. Повторы показываются при следующем открытии сайта; внешние уведомления не приходят.

Если прогресс изменится в другой вкладке, прежняя вкладка покажет предупреждение и прекратит сохранение до обновления страницы.

Уроки — опорная программа для практики, а не сертификат уровня C2. Озвучка зависит от голосов на устройстве; запись позволяет послушать себя, без автоматической оценки произношения. Ускорение обучения на пользователях Say it пока не измерено.
