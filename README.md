# Say it — веб-тренажёр английского

[Открыть Say it](https://safal207.github.io/english-zero-to-fluent-pages/)

Бесплатный тренажёр английского: 42 опорных урока от первых фраз до сложного разговора, 126 упражнений, 168 карточек и разговорная практика. Интерфейс адаптирован для телефона.

Этот репозиторий содержит только файлы веб-приложения, без истории основного приватного репозитория и без пользовательских сохранений. Для работы не нужны платные API или ключи.

## Публикация

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. После обновления файлов в этой ветке GitHub автоматически обновляет сайт. Это отдельная копия: изменения в основном приватном репозитории нужно сначала перенести сюда.

## Прогресс

Прогресс хранится в браузере. При переходе с другого адреса скачай резервную копию в разделе «Мой прогресс» прежнего сайта и загрузи её здесь. Аудиозаписи нужно сохранять отдельно. Сервер не получает учебный прогресс и записи голоса.

Уроки — опорная программа для практики, а не сертификат уровня C2. Озвучка зависит от голосов на устройстве; запись позволяет послушать себя, без автоматической оценки произношения.
