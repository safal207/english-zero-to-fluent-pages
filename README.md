# Say it — веб-тренажёр английского

[Открыть Say it](https://safal207.github.io/english-zero-to-fluent-pages/)

Бесплатный тренажёр английского с первым устным ответом сразу после открытия. Выбери короткий режим на 2, 5 или 10 минут: послушай собеседника, повтори ответ с опорой, скажи без текста и вернись к нему позже. 42 опорных урока, 126 упражнений и 168 карточек остаются в программе. Интерфейс адаптирован для телефона.

Можно добавить до 20 своих фраз за раз из интересного видео или текста, использовать их в диалоге и вернуться к ним по памяти через два дня. Всего хранится до 2000 личных фраз. Сайт готовит текст задания для внешнего чата, но сам ничего туда не отправляет.

Этот репозиторий содержит только файлы веб-приложения, без истории основного приватного репозитория и без пользовательских сохранений. Для работы не нужны платные API или ключи.

## Публикация

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. После обновления файлов в этой ветке GitHub автоматически обновляет сайт. Это отдельная копия: изменения в основном приватном репозитории нужно сначала перенести сюда.

## Прогресс

Прогресс, незавершённый шаг урока, личные фразы и назначенные повторы хранятся в браузере. При переходе с другого адреса скачай резервную копию в разделе «Мой прогресс» прежнего сайта и загрузи её здесь. Аудиозаписи нужно сохранять отдельно: они остаются только в памяти вкладки до ухода с экрана. Сервер не получает учебный прогресс и записи голоса. Повторы показываются при следующем открытии сайта; внешние уведомления не приходят.

Уроки — опорная программа для практики, а не сертификат уровня C2. Озвучка зависит от голосов на устройстве; запись позволяет послушать себя, без автоматической оценки произношения.
