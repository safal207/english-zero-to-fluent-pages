# Say it — веб-тренажёр английского

[Открыть Say it](https://safal207.github.io/english-zero-to-fluent-pages/)

Бесплатный тренажёр английского с первым устным ответом сразу после открытия. Выбери режим на 2, 5 или 10 минут: послушай собеседника, повтори ответ с опорой и скажи без текста. При повторении сначала вспомни ответ и оцени первую попытку, затем сравни с образцом. После самостоятельного ответа приложение предложит следующую ситуацию, если другие повторы ещё не наступили. В 10-минутном режиме каждая из 42 тем превращается в разговор из трёх реплик: знакомый вопрос, новая ситуация и её продолжение. Перенос в новую ситуацию оценивается отдельно. В программе также 126 упражнений и 168 карточек. Интерфейс адаптирован для телефона.

Можно добавить до 20 своих фраз за раз из интересного видео или текста и сохранить ссылку на источник. Задание для диалога видно сразу, а отметить его выполнение можно на следующий день. Ещё через два дня приложение предложит вспомнить фразы и вернуться к материалу. Всего хранится до 2000 личных фраз. Сайт готовит текст задания для внешнего чата, но сам ничего туда не отправляет.

Этот репозиторий содержит только файлы веб-приложения, без истории основного приватного репозитория и без пользовательских сохранений. Для работы не нужны платные API или ключи.

## Публикация

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. После обновления файлов в этой ветке GitHub автоматически обновляет сайт. Это отдельная копия: изменения в основном приватном репозитории нужно сначала перенести сюда.

## Прогресс

Прогресс, незавершённый шаг урока и короткой практики, введённый в ней текст, личные фразы, назначенные повторы и история до 300 попыток хранятся в браузере. История попыток не содержит ответы, аудио или текст источников. Раздел «Мой прогресс» показывает долю самостоятельных ответов после 48 часов, ответы на дополнительные реплики и время до отметки об ответе; неудачные попытки в медиану времени не входят. Дополнительные реплики могут стать знакомыми при повторении. Это самооценка, не измерение скорости речи или результата обучения. При переходе с другого адреса скачай резервную копию в разделе «Мой прогресс» прежнего сайта и загрузи её здесь. Аудиозаписи нужно сохранять отдельно: они остаются только в памяти вкладки до ухода с экрана. Сервер не получает учебный прогресс и записи голоса. Повторы показываются при следующем открытии сайта; внешние уведомления не приходят.

Если прогресс изменится в другой вкладке, прежняя вкладка покажет предупреждение и прекратит сохранение до обновления страницы.

Уроки — опорная программа для практики, а не сертификат уровня C2. Озвучка зависит от голосов на устройстве; запись позволяет послушать себя, без автоматической оценки произношения. Ускорение обучения на пользователях Say it пока не измерено.
